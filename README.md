# 书签整理助手

不需要构建或安装依赖。适用于 Chrome 114 及以上版本，Manifest V3。

## 安装

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择 `F:\code\chrome`（包含 manifest.json 的目录）。
4. 点击浏览器工具栏的拼图按钮，将「书签整理助手」固定；点击插件图标打开管理页。

## 使用

- 左侧为收藏夹目录树，可展开、收起、选择目录。右侧列出当前范围的书签。
- 勾选「包含子目录」可以查看和检测所选目录下的全部书签；取消后仅查看直接属于该目录的书签。
- 点击「开始检测」，以最多 5 个并发请求检测当前范围；可随时停止。切换目录不改变已开始的检测范围，进度文字会标明正在检测的目录。
- 检测不受搜索和状态筛选影响；搜索与筛选仅改变列表显示。
- 点击「选择失效链接」选中当前列表中确认返回 404 / 410 的书签，再点击「删除所选」并确认。
- 拖动书签行到左侧目标目录即可移动。拖动已勾选的书签可一起移动全部所选书签；也可通过「移动所选」选择目标目录。
- 选择一个目录后可以新建子目录、重命名、删除目录。删除目录会同时删除全部子目录和书签，操作前会显示确认提示。
- Chrome 自带的顶层目录和受管理的目录不可删除或重命名。

## 检测说明与数据

- 首先发送 HEAD；如果服务器返回错误状态，使用 GET 再验证，并取消响应体读取。每个链接总等待时间最多 12 秒。
- 只有最终返回 404 / 410 的链接显示「失效」。401、403、429、服务器错误、DNS/证书/网络错误以及超时均显示为「待确认」类状态，不能据此断定链接永久失效。
- 返回 200 的登录页、软 404 页面等无法仅凭状态码辨别，请按需手动打开确认。
- 仅检测 HTTP / HTTPS；内部地址、文件链接、书签脚本等显示「不支持检测」。书签脚本不会在管理页执行。
- 检测请求不携带登录凭据；部分需要登录的网站可能显示访问受限。
- 检测在管理页中运行，关闭或刷新页面会中止检测并清空本次结果。
- 插件使用 Chrome bookmarks 权限直接管理本机浏览器书签；HTTP / HTTPS 网站访问权限用于链接检测。没有远程脚本、统计或第三方服务器上传；仅在用户发起检测时请求书签指向的网站。
- 移动、新建、重命名和删除会立即写入 Chrome，并可能由 Chrome 账户同步。删除不可在本插件中撤销；如需备份，可先通过 Chrome 自带书签管理器导出 HTML。

## 开发与验证

运行 `npm test` 执行链接状态分类、HEAD/GET 回退、超时、取消及目录范围测试。

手动验收建议：加载扩展，在测试目录中创建几个书签，检查目录树、子目录开关、新建/重命名、单项及多项拖拽、移动所选、检测与停止、筛选及删除确认。使用 `https://example.com` 测试可访问状态，使用受控测试服务的 404 / 410 地址检查失效清理。不要直接用重要书签做删除测试。
